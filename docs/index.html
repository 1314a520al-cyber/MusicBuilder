✨ 核心特性

🎧 三平台聚合

网易云 / QQ音乐 / 酷狗一键切换：每日推荐、排行榜、搜索、歌单全部跟随平台。

📡 添加音乐源

可自行添加音乐源接口；需要卡密的源填写卡密，不需要则无需填写，统一管理、随时启停。

⚡ 自动识别音源

官方地址不可用或为试听片段时，并发请求所有已启用音乐源，最快可用者自动播放。

🔄 同步歌单

购买后带同步能力的音源，一键把歌单同步到音乐库，支持整单播放、随机播放与站内搜索。

🎚️ 播放能力拉满

多档音质、歌曲下载、锁屏与后台播放、播放队列、倍速、睡眠定时、逐行歌词。

🧊 液态玻璃界面

原生 Liquid Glass 质感，深浅色自适应，多套主题色，封面取色全局跟随。

🧹 清除缓存

一键清理网络图片与临时数据，不触碰已下载歌曲、字体、壁纸与登录信息。

🔐 账号同步

支持网易云 / QQ / 酷狗登录，同步云端歌单、收藏与账号标识。

📲 安装说明

本页提供的是未签名 IPA，普通苹果手机不能直接点击安装，需要借助签名工具：

· TrollStore：导入后免签永久安装（需设备在支持范围）
· ESign / SideStore / AltStore / 爱思助手：用自己的证书重签后安装

⚠️ 重要提示

  1. 本项目为第三方 API 音乐客户端，并非网易云、QQ音乐、酷狗官方软件，使用存在账号风险。
  2. IPA 必须自签后才能安装；仅供个人学习研究，禁止用于商业及非法用途。
