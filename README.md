# 📖 笔趣阁 - 小说阅读APP

一款精美的iOS小说阅读应用，液态玻璃UI设计，支持海量免费小说源。

## ✨ 功能特性

### 📚 书架
- 收藏喜欢的小说，自动记录阅读进度
- 网格布局展示，支持编辑模式
- 长按可移除小说

### 🏠 书城
- 轮播图推荐，分类浏览
- 折叠式分类选择（玄幻/都市/言情/历史/科幻等）
- 热门推荐，下拉刷新
- 精选小说网格展示

### 🔍 搜索
- 搜索小说和作者
- 搜索历史自动保存
- 热门搜索推荐
- 多源聚合搜索，自动去重

### 📖 阅读
- 沉浸式阅读体验
- 5种阅读背景主题（夜间/护眼/羊皮纸/清新/粉色）
- 字体大小12-28可调
- 行间距2-20可调
- 屏幕常亮开关
- 上下章切换
- 章节目录快速跳转
- 单章下载

### ⬇️ 下载管理
- 整本下载或单章下载
- 选择保存文件夹，支持新建文件夹
- 下载进度实时显示
- 按小说分组管理
- 支持单章删除和全部删除
- 显示总下载大小

### 🗑️ 缓存管理
- 实时显示缓存大小
- 一键清除缓存
- 不影响已下载小说

### ⚙️ 设置
- 5种APP主题颜色（橙日/海蓝/翠绿/紫霞/粉红）
- 阅读设置（字体/行距/屏幕常亮/阅读进度）
- 下载设置（仅WiFi下载/自动下载更新）
- 检查更新

### 🔌 小说源管理
- 内置6个稳定免费源
- 简化添加源：只需填写名称和网站地址
- 自动识别搜索、阅读、下载功能
- 支持开关和删除自定义源
- 自动探测搜索路径
